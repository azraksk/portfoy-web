Myblog Web Sitesi Projesi

Bu proje, PHP, MySQL, HTML, CSS ve JavaScript kullanarak geliştirdiğim blog web sitesidir. Kullanıcılar blog yazabilir, MySQL ile bloglar ve kullanıcılar database'de saklanır.

Kullanılan Teknolojiler

  • PHP
  • MySQL
  • HTML5
  • XAMPP
  • HTML5
  • CSS3 (Responsive tasarım)
  • JavaScript (Popup mesajlar ve form gönderimi)

Linkler

  • GitHub Proje Sayfası

Öğrendiklerim

Modern, dinamik ve kullanıcı dostu bir blog sistemi başarıyla geliştirildi. Sistem teknik olarak sorunsuz çalışıyor ve tatmin edici bir kullanıcı deneyimi sunuyor.
